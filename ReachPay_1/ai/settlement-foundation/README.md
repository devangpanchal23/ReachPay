# ReachPay Production engineering memory

Load `PROJECT_CONTEXT.md`, `BUSINESS_FLOW.md`, `ARCHITECTURE.md`, `SECURITY.md`, and `KNOWN_LIMITATIONS.md` before changing this package. The audit under `audits/` describes the prototype with file/line evidence.

Keep this directory free of secrets and customer data. Never record API keys, credentials, card data, passwords, OTPs, private bank data, raw provider payloads, or unsanitized logs. Record task date, scope, files, outcomes, tests, errors/root causes, and remaining risks in sanitized notes. A provider name in documentation is not proof of activation or production readiness.
